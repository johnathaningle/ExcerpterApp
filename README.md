# Excerpter
[![CI](https://github.com/johnathaningle/ExcerpterApp/actions/workflows/ci.yml/badge.svg)](https://github.com/johnathaningle/ExcerpterApp/actions/workflows/ci.yml)

PDF note taking and annotation made easy. Open any PDF, highlight text with customizable colors, attach notes, and export your annotations as a text file.

## Installation

[Obtanium](https://github.com/ImranR98/Obtanium) can install and auto-update this app directly from GitHub releases:

1. Install Obtanium from [F-Droid](https://f-droid.org/packages/com.imranr.Obtanium/) or [GitHub](https://github.com/ImranR98/Obtanium/releases).
2. Open Obtanium and tap **Add App**.
3. Enter `https://github.com/johnathaningle/ExcerpterApp` as the source URL.
4. Tap **Add** and then **Install** when prompted.

Obtanium will check for new releases automatically.

## Building

```
./gradlew assembleDebug
```
